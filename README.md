# Customer Churn Analysis

A SQL-based customer analytics project focused on churn rate, contract type, tenure and support activity.

## Tools
- SQL
- Python (Pandas, Matplotlib)

## Business Questions
- What is the overall churn rate?
- Which contract types have the highest churn?
- How does churn vary by tenure?
- Is support activity associated with churn?
- Which customer segments should receive retention attention?

## Dataset Note
Generated practice data for portfolio demonstration; it is not employer/client data.
