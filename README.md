# Customer Churn Analysis — SQL Portfolio Project

## Overview
An end-to-end customer analytics project using SQL and Python to identify churn patterns, segment customers, and support retention decisions.

## Objective
Measure churn, understand major churn drivers, and identify customer groups that may require retention attention.

## Business Questions
- What is the overall churn rate?
- Which contract types have the highest churn?
- How does churn vary across tenure groups?
- Is support activity associated with churn?
- Which customer segments show elevated risk?

## Toolkit
**SQL** • **Python** • **Pandas** • **Matplotlib** • Data Cleaning • Segmentation • KPI Analysis

## Workflow
1. Inspect and validate customer records.
2. Prepare analysis-ready data.
3. Calculate churn KPIs with SQL.
4. Segment customers by contract and tenure.
5. Validate patterns through Python analysis.
6. Translate findings into retention-focused recommendations.
